# فارسی برای DeepSeek Harness

افزونهٔ مستقل جامعهٔ کاربری، ساخته‌شده توسط [MiRHaDi](https://github.com/MiRHaDi). این افزونه ۲۴۰ رشته را در شش بخش ترجمه می‌کند و گزینهٔ «فارسی» را به انتخاب زبان می‌افزاید. صفحه در حالت فارسی راست‌چین می‌شود و کد، ترمینال و ویرایشگرها چپ‌چین می‌مانند.

این نسخه با DeepSeek Harness **0.1.6-alpha.2** و Chrome **153.0.8010.52** روی ویندوز آزمایش شده است. افزونه، خود برنامه را نصب یا ارتقا نمی‌دهد. ترجمهٔ کل برنامه کامل نیست؛ راه‌اندازی اولیه، تنظیمات ارائه‌دهنده، برخی پنل‌ها و کنترل‌های نوشتن پیام هنوز انگلیسی هستند.

فایل `dsh-persian-rtl-0.1.0.tgz` را از [نسخه‌های منتشرشده](https://github.com/MiRHaDi/dsh-persian-rtl/releases) دریافت کنید و در نصب سازگار DSH اجرا کنید:

```sh
dsh plugin --profile web add ./dsh-persian-rtl-0.1.0.tgz
dsh --profile web --no-open
```

سپس نشانی محلی چاپ‌شده توسط برنامه را باز کنید و از مسیر Settings → General → Language، فارسی را انتخاب کنید. برای انتخاب زبان نیازی به کلید API نیست. اولویت زبان ذخیره‌شدهٔ شما حفظ می‌شود. برای آزمایش مستقل، پیش از اجرا متغیر `DSH_HOME` را به پوشه‌ای خالی تنظیم کنید.

برای حذف:

```sh
dsh plugin --profile web remove dsh-persian-rtl
```

پس از حذف، صفحه را دوباره بارگذاری کنید. جهت صفحه هنگام خروج از فارسی به حالت قبلی بازمی‌گردد. تقویم شمسی و تبدیل ارقام در این نسخه اضافه نشده‌اند. شش آزمون خودکار و آزمایش در رابط واقعی برنامه انجام شده؛ اجرای گفت‌وگو با مدل و همهٔ اندازه‌های صفحه آزمایش نشده‌اند. جزئیات پوشش، روش اجرای تست و محدودیت‌ها در [راهنمای انگلیسی](README.md) آمده است.

این پروژه با کمک هوش مصنوعی آماده و آزمایش شده است و وابستگی رسمی به تیم DeepSeek ندارد. گزارش اشکال و بازبینی ترجمه‌ها توسط فارسی‌زبانان کمک‌کننده است.
