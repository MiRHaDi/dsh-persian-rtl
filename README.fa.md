# فارسی برای DeepSeek Harness

افزونهٔ مستقل جامعهٔ کاربری، ساخته‌شده توسط [MiRHaDi](https://github.com/MiRHaDi). این افزونه ۳۹۵ رشته را در هفت بخش ترجمه می‌کند و گزینهٔ «فارسی» را به انتخاب زبان می‌افزاید. صفحه در حالت فارسی راست‌چین می‌شود و کد، ترمینال و ویرایشگرها چپ‌چین می‌مانند.

این نسخه با DeepSeek Harness **0.1.6-alpha.2** و Chrome **153.0.8010.52** روی ویندوز آزمایش شده است. افزونه، خود برنامه را نصب یا ارتقا نمی‌دهد. ترجمهٔ کل برنامه کامل نیست؛ راه‌اندازی اولیه، تنظیمات ارائه‌دهنده، برخی پنل‌ها هنوز انگلیسی هستند.

ترجمهٔ ۱۵۵ رشتهٔ بخش گفت‌وگو در این شاخه هنوز منتشر نشده است. نسخهٔ v0.1.0 همان ۲۴۰ رشتهٔ قبلی را دارد. برای آزمایش این شاخه، `npm ci`، `npm test` و `npm pack` را اجرا و بستهٔ محلی حاصل را نصب کنید. صف‌کردن پیام و هدایت اجرای جاری عبارت‌های مجزا دارند. اجرای کامل نسخهٔ alpha جدید هنوز تأیید نشده است؛ بررسی نسخهٔ RC در انتهای این راهنما آمده است.

فایل `dsh-persian-rtl-0.1.0.tgz` را از [نسخه‌های منتشرشده](https://github.com/MiRHaDi/dsh-persian-rtl/releases) دریافت کنید و در نصب سازگار DSH اجرا کنید:

```sh
dsh plugin --profile web add ./dsh-persian-rtl-0.1.0.tgz
dsh --profile web --no-open
```

سپس نشانی محلی چاپ‌شده توسط برنامه را باز کنید و از مسیر Settings → General → Language، فارسی را انتخاب کنید. برای انتخاب زبان نیازی به کلید API نیست. اولویت زبان ذخیره‌شدهٔ شما حفظ می‌شود. برای آزمایش مستقل، پیش از اجرا متغیر `DSH_HOME` را به پوشه‌ای خالی تنظیم کنید.

برای حذف:

```sh
dsh plugin --profile web remove dsh-persian-rtl
```

پس از حذف، صفحه را دوباره بارگذاری کنید. جهت صفحه هنگام خروج از فارسی به حالت قبلی بازمی‌گردد. تقویم شمسی و تبدیل ارقام در این نسخه اضافه نشده‌اند. ۹ آزمون خودکار برای هر نسخه و آزمایش در رابط واقعی برنامه انجام شده؛ اجرای گفت‌وگو با مدل و همهٔ اندازه‌های صفحه آزمایش نشده‌اند. جزئیات پوشش، روش اجرای تست و محدودیت‌ها در [راهنمای انگلیسی](README.md) آمده است.

این پروژه با کمک هوش مصنوعی آماده و آزمایش شده است و وابستگی رسمی به تیم DeepSeek ندارد. گزارش اشکال و بازبینی ترجمه‌ها توسط فارسی‌زبانان کمک‌کننده است.

در این شاخه، پیش‌نویس فارسی/انگلیسی در برنامهٔ واقعی و Chrome 153.0.8010.54 آزمایش شد و پس از تغییر زبان حفظ شد. در عرض ۳۶۰ پیکسل سرریز افقی صفحه دیده نشد؛ بریدگی برچسب حالت اجرا در بازبینی بعدی با Chrome 154.0.8037.98 اصلاح شد: کنترل‌های فضای کاری و حالت اجرا هنگام کمبود عرض در حالت فارسی به خط بعد می‌روند. عرض‌های ۳۲۰، ۳۶۰، ۷۶۸ و ۱۲۸۰ پیکسل و بازشدن منوی حالت آزمایش شدند. پیامی به مدل ارسال نشد.

رابط LocaleRuntime و قرارداد پارامترهای ترجمه در سه نسخهٔ دقیق 0.1.6-alpha.2، 0.2.0-rc.2 و 0.2.1-alpha.1 آزمایش می‌شود؛ مجموعاً ۲۷ اجرای تست. وابستگی‌های نسخه‌های جدید جدا نصب می‌شوند تا نسخه‌های Cordis با هم تداخل نکنند. در دو نسخهٔ جدید، ۳۸۲ کلید همچنان ترجمه دارند و ۳۶۶ و ۳۶۸ کلید جدید به انگلیسی نمایش داده می‌شوند. نسخهٔ 0.2.1-alpha.1 هنوز فقط در سطح API و دیکشنری آزمایش شده است. برای 0.2.0-rc.2، نصب و حذف با CLI رسمی و رابط وب واقعی نیز جداگانه آزمایش شدند.

بستهٔ محلی همین شاخه روی DSH 0.2.0-rc.2 نصب شد و تغییر زبان، حفظ پیش‌نویس، چهار عرض صفحه و منوی حالت با Chrome 154.0.8037.98 موفق بودند. پس از حذف و اجرای مجدد، گزینهٔ فارسی و CSS راست‌چین باقی نماندند. تست اکنون ذخیره‌شدن زبان را در یک محیط مرورگر مستقل با زبان پیش‌فرض مخالف تأیید می‌کند تا نمایش موقت و خوش‌بینانهٔ رابط باعث نتیجهٔ اشتباه نشود. این تأیید برای بستهٔ محلی شاخه است؛ فایل منتشرشدهٔ v0.1.0 روی RC دوباره آزمایش نشده است.
